# Frozen physical generalization protocol

Status: **NOT_RUN on primary 750k**. Local CPU physics smoke is not model/control evidence.

The primary SHA256 is `f44afd1992e194fd0d70b766398de7ad3d0ca880c55b46e3b8c34ad9dade013b`. The loader checks both model and optimizer file hashes, restores the original configuration and RunningScale, disables parameter gradients, and preserves MPPI (horizon 3, 512 candidates, 6 iterations). A runtime guard raises if agent.update or either optimizer.step is called. Model/optimizer/scale hashes and checkpoint file hashes must match before/after.

The main stage evaluates all 12 fixed physical conditions on the same **20 held-out seeds 43000001–43000020**, with 1000 steps per episode: **240 episodes, at most 240,000 transitions**. Nominal k=1 is included for both families. The final scalar reward and observation/action semantics remain those in the inspected environment. `eval_mode=True` preserves the repository's stochastic MPPI/Gumbel selection; each episode resets all policy/environment RNG seeds. Identical initial randomness does not imply identical later random decisions when visited states differ.

Frozen evaluation requires a completed non-smoke `physical` gate with the same protocol hash and covered conditions. Execute only after reviewing the physical readbacks and numerical validity. Optional secondary 950k runs require a completed primary Frozen gate and a separately labelled sensitivity split. For a paired 750k-versus-950k sensitivity study, run both on the reserved sensitivity seeds; never call checkpoints independent training seeds. 500k is not in the default command plan.

Raw episode files contain root/joint qpos/qvel/qacc, body orientation/velocity, control/actuator forces, contacts, observations, actions and rewards. Step CSVs contain physical readback, scheduler clock, reward, velocity, control cost, action magnitude/saturation/change and termination flags. Summary outputs report return mean/median/sample SD/bootstrap CI, return per transition, forward velocity, control cost, length, termination/truncation counts, exposure and joint-wise action statistics. Nominal paired differences resample episode seeds with a fixed bootstrap RNG. Confidence intervals are exploratory and not multiplicity-corrected. One training seed limits population claims.

Saturation is the fraction of action components with |a| ≥ 0.99. Smoothness is RMS successive-action difference. Control cost is minus reward_ctrl, not an assumed physical energy expenditure. Return/time-limit completion is not binary task success. Reward contains forward velocity and action penalty, with no direct mass/damping input in the inspected HalfCheetah implementation.

`summarize` regenerates `frozen_generalization.csv`, `action_diagnostics_by_severity.csv`, return/velocity/control plots, action plots and time series. `latent` on these raw held-out trajectories independently produces prediction-error tables. `--physical-reference` adds a plot relating controlled response to closed-loop return; it does not make the two measurements causal equivalents. Preserve the entire grid, including irregular/nonmonotone results. Low return alone does not establish model-error causality or a need for adaptation.
