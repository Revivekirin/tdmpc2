# NS-Gym results

Local outputs from `experiments/nsgym/scripts/smoke.py` belong here. Existing output files are never overwritten. Four `*-validation.json` artifacts record the initial real-MuJoCo checks, with physical parameter logs separated from agent inputs. Results remain git-ignored unless explicitly added; copy this directory when backing up experiment data. Validation summaries are tracked under `experiments/nsgym/validation/`.
